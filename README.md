# Blade & Soul NEO 時間表工具
## **🇹🇼 中文（繁體）**
用於整理並顯示《劍靈 NEO》野外 Boss 與 儀式系統 的提示時間。<br>

支援 台服 / 日服 的語系與時區自動切換，<br>
並提供 玩家回報機制，協助社群共同補齊與修正時間資料。

### 🔗 Demo
台服：<https://bit.ly/BnSNEOtimeList><br>
日服：<https://x.gd/rkSjt>　`2026/03/11 停止服務`


## ✨ 功能特色
### 🌏 語系與時區自動判定
- 依使用者系統時區自動切換
  - UTC+8 → 中文（台服）
  - UTC+9 → 日文（日服）

- 支援手動切換語系（設定會儲存在瀏覽器）

### ⏰ 即時伺服器時間顯示
- 顯示 台灣 / 日本 伺服器時間
- 每秒更新
- 顯示完整日期與星期

### 📊 任務時間表
- 所有資料來自 timeList.xlsx
- 依星期自動顯示：
  - 前一小時任務（條件顯示）
  - 當前任務
  - 接下來 2 小時
  - 其他時間（可展開 / 收合）
- 支援：
  - Excel 時間格式
  - 不確定時間標記 [?]
  - 跨日顯示（隔日凌晨）

### 🔧 維修時段處理
- 自動識別以下內容為維修：
  - 例行維護中
  - 定期メンテナンス中
- 連續維修時段會自動合併顯示
- 維修中仍可預覽後續任務

### 🎯 Boss 出現時間判定
- 顯示的是「系統出字時間」
- 實際 Boss 出現時間約為：
  - 儀式：+3 分鐘（30分鐘內沒人消滅 會自動消失）
  - 水月 / 白青野王：+5 分鐘
- 超過時間後會自動顯示為灰色

### 📝 玩家回報系統（LocalStorage）
- 玩家可回報：
  - 任務類型
  - 回報種類（時間 / 其他）
  - 自由備註（時間、地點）

### 📄 Excel 格式說明
**Sheet 名稱**
  - 中文：timeList_ZH
  - 日文：timeList_JP

**欄位格式**
| 欄位 | 說明 |
| :-- | :-- |
| Week-zh | 星期（日、一、二…） |
| gishiki-time / zh / jp | 儀式 |
| mizuki-time / jp | 水月野王`（2026/01/21 台灣伺服器刪除）` |
| shirao-time / zh / jp | 白青野王 |
| mizuki-time / zh | 水月野王`（2026/01/21 台灣伺服器追加）` |

**補充規則**
- 時間可使用 HH:MM 或 Excel 時間格式
- 不確定時間加入 \_?（例：19:30_?）
