# Blade & Soul NEO タイムツール
## **🇯🇵 日本語版**
『ブレイドアンドソウル NEO』における フィールドボス および 儀式システム の通知時間を整理・表示します。<br>

台湾サーバー / 日本サーバーの言語・タイムゾーンに自動対応し、<br>
プレイヤー報告機能を通じて、コミュニティ主導で時間データの補完・修正が可能です。

### 🔗 デモ
台湾サーバー：https://bit.ly/BnSNEOtimeList<br>
日本サーバー：https://x.gd/rkSjt　`2026/03/11 サービス終了`

## ✨ 機能概要
### 🌏 言語・タイムゾーン自動判定
- ユーザーのシステムタイムゾーンに応じて自動切替
  - UTC+8 → 中国語（台湾サーバー）
  - UTC+9 → 日本語（日本サーバー）

- 手動での言語切替にも対応（設定はブラウザに保存）

### ⏰ 即時伺服器時間顯示
- 台湾 / 日本サーバー時間を表示
- 1 秒ごとに自動更新
- 日付および曜日を含む完全表示

### 📊 タスクタイムテーブル（Excel 連動）
- すべてのデータは timeList.xlsx から取得
- 曜日に応じて自動表示：
  - 直前 1 時間のタスク
  - 現在のタスク
  - 次の 2 時間
  - その他の時間帯（展開 / 折りたたみ可能）
- 対応機能：
  - Excel 時間形式
  - 不確定時間マーク [?]
  - 日跨ぎ表示（翌日深夜）

### 🔧 メンテナンス時間の処理
- 以下の文言を自動的にメンテナンスとして判定：
  - 例行維護中
  - 定期メンテナンス中
- 連続するメンテナンス時間は自動的に結合表示
- メンテナンス中でも後続タスクの確認が可能

### 🎯 ボス出現時間の目安
- 表示される時間は「システムメッセージ表示時刻」
- 実際の出現時間目安：
  - 儀式：約 +3 分
  - 水月 / 白青フィールドボス：約 +5 分
- 時間経過後は自動的にグレー表示（終了）

### 📝 プレイヤー報告システム（LocalStorage）
- 報告可能内容：
  - タスク種別
  - 報告タイプ（時間 / その他）
  - 自由コメント（時間・場所など）
- すべてのデータは利用者のブラウザ内にのみ保存（バックエンドなし）

### 📄 Excel フォーマット仕様
**シート名**
- 中国語：timeList_ZH
- 日本語：timeList_JP

**カラム定義**
| カラム名 | 説明 |
| :-- | :-- |
| Week-zh | 曜日（日・月・火…） |
| gishiki-time / zh / jp | 儀式 |
| mizuki-time / zh / jp | 水月フィールドボス  `（2026/01/21 フィールドボス削除）` |
| shirao-time / zh / jp | 白青フィールドボス |

**補足ルール**
- 時刻は HH:MM または Excel 時刻形式を使用可能
- 不確定な時刻は \_? を付与（例：19:30_?）
